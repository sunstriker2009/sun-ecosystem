# Decision 0002 — Rename HALO to ORYVA

**Date:** 2026-10-30  
**Status:** Accepted

## Context
HALO was initially confirmed for a reusable identity and security product, but an existing IAM use of the name raised potential brand-confusion concerns. The product owner requested an alternative and explicitly selected **ORYVA**.

## Decision
**ORYVA by Sun** is confirmed as SUN-001 and supersedes HALO. Retain the positioning **Identity. Trust. Protection.** and the technical namespace **Sun.Security**. Use **sun-oryva** as the proposed repository name, **Sun.Security.*** for backend packages and **@sun-security/*** for frontend packages.

## Consequences
Update future references from HALO to ORYVA. Preserve this record for history. ORYVA's internal approval does **not** imply completed trademark, domain or package clearance; record that separately before commercialization.
