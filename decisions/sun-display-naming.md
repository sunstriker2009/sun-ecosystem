# SUN display naming and brand character

Use PascalCase for approved display names in documents, interfaces, registries, and the repository gallery. The current spellings are Strata, Foundry, Workbench, Outpost, and CodeFolio. Preserve the spaces and acronym casing in Foundry Pilot and MarketPilot AI. Use SUN for the parent brand and “by Sun” for the endorsement.

Panoramic README banner artwork uses all-caps product names. Existing repository slugs, SUN IDs, technical identifiers, and approved artwork retain their existing forms.

Use product purpose, audience, and the work each product supports to guide naming and visual design. Choose imagery by product family and purpose. A recognizable visual connection to the Sun should grow from the artwork itself, as with CodeFolio’s sunrise arc and Workbench’s sunlight. The “by Sun” endorsement provides a consistent verbal connection.

See the [Naming Guidelines](../branding/NAMING-GUIDELINES.md#display-names-and-artwork) and [Brand Guidelines](../branding/BRAND-GUIDELINES.md#brand-character).
