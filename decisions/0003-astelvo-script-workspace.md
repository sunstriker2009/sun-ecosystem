# ASTELVO by Sun

Date: 2026-11-12
Status: Accepted — internal product naming
Product ID: SUN-009

## Decision
The product owner approved the recommended ASTELVO name and kickoff with "Sounds good, kick off" after the naming and scope proposal. Use ASTELVO by Sun, tagline "Connect. Script. Explore.", capability namespace Sun.Workspace and repository convention sun-astelvo.

## Rationale
A pronounceable seven-letter invented name with stellar associations fits SUN while leaving room beyond database scripting. Keep technical capability naming independent of the public brand. Existing SUN-002 through SUN-008 proposals retain their IDs and status.

## Scope and boundaries
The initial product is a local desktop scripting workspace for SQL Server and PostgreSQL. It owns profiles, connection entries, profile-local script folders, editor sessions and execution results. Support single-attempt automatic connection on profile activation, explicit recovery after failure, Windows integrated authentication and optional Kubernetes forwarding. Future providers may include SQLite, MySQL, Redis and HTTP/GraphQL.

This repository records brand decisions only. Architecture, delivery milestones, code and repository-governance adoption evidence belong in sun-astelvo once available.

## Clearance
Internal naming approval is complete. Commercial clearance remains PENDING: no trademark, domain, GitHub, NuGet or npm availability claim is made. Initial exact-name web searches surfaced no obvious ASTELVO match; that is not commercial clearance.

## Registry ID correction — 2026-11-14

The product owner changed the SUN registry policy to assign IDs **sequentially upon product confirmation**, rather than reserving IDs for proposals. ASTELVO is therefore **SUN-002** (previously SUN-009). The original decision text above is retained as historical context; its ID and proposal-reservation statements are superseded by this correction. The proposed names ORBIT, NOVA, PRISM, PULSAR, LUMEN, BEACON and FORGE no longer hold reserved IDs. The next approved product receives SUN-003.
