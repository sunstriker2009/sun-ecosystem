# SUN reusable prompts

Shared prompts for consistent SUN collaboration and development workflows.

| Prompt | When to use |
|---|---|
| [Thread continuation](thread-handoff.md) | Prepare a self-contained handoff before continuing a long conversation in a fresh thread |

Open a prompt and copy its fenced text into the relevant conversation. These prompts support the [SUN Git Workflow & Merge Policy](../governance/GIT-WORKFLOW.md); they do not override repository instructions, review requirements, or paused automation.

Keep reusable prompts here and project-specific generated handoffs in the relevant project's documentation.
