# SUN Ecosystem handoff

Read the [Foundry handoff](https://github.com/sunstriker2009/sun-foundry/blob/main/docs/GOVERNANCE-HANDOFF.md) for current operations, recovery and delivery status. Check live GitHub state before resuming a run or making registry changes.

Ecosystem owns SUN naming, branding and Git governance policy. Foundry owns the product registration lifecycle, registries, repository catalog and gallery. Use the [SUN workflow handbook](../workflows/README.md) to find the owning workflow and its operating procedure.
