# SUN registry and repository gallery

Foundry maintains the [operational product catalog](https://github.com/sunstriker2009/sun-foundry/blob/main/registry/product-catalog.json), [published identities](https://github.com/sunstriker2009/sun-foundry/blob/main/registry/products.json), and [repository catalog](https://github.com/sunstriker2009/sun-foundry/blob/main/registry/repositories.json). The [Foundry gallery](https://github.com/sunstriker2009/sun-foundry/blob/main/registry/GALLERY.md) is generated from those records and validated against the icon files and hashes tracked in Foundry.

Use the [Foundry workflow handbook](https://github.com/sunstriker2009/sun-foundry/blob/main/docs/WORKFLOWS.md) for registration, branding uploads, icon reconciliation, and renames. SUN naming and branding decisions remain in this repository.
